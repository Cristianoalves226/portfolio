# Portfólio — Cristiano Alves de Campos

Landing page pessoal de portfólio para apresentação profissional, projetos e tecnologias.

## 🚀 Sobre o projeto

Projeto desenvolvido para apresentar o perfil de **Cristiano Alves de Campos** como desenvolvedor, reunindo informações sobre sua stack, projetos públicos do GitHub e formas de contato.

A página foi construída com foco em um visual moderno, responsivo e fácil de personalizar.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Google Fonts (Inter e JetBrains Mono)
- Git / GitHub

## 📂 Estrutura

```text
portfolio/
├── index.html   # Estrutura e conteúdo da página
├── style.css    # Estilos e responsividade
├── script.js    # Interações do menu mobile
└── README.md    # Documentação do projeto
```

## ✨ Recursos

- Layout moderno para portfólio de desenvolvedor
- Design responsivo para desktop, tablet e celular
- Menu de navegação mobile
- Seções de apresentação, tecnologias, projetos, atuação e contato
- Links para projetos reais do GitHub
- Links para GitHub, LinkedIn e X/Twitter
- Estrutura simples, sem dependências de frameworks

## ▶️ Como executar

Não é necessário instalar dependências.

1. Clone o repositório:

```bash
git clone https://github.com/Cristianoalves226/portfolio.git
```

2. Entre na pasta:

```bash
cd portfolio
```

3. Abra o arquivo `index.html` no navegador.

Também é possível utilizar uma extensão como **Live Server** no VS Code para executar o projeto localmente.
